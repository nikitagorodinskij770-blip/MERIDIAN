# MERIDIAN — Digital Asset Exchange (макет / песочница)

Институциональный криптообменник в белом строгом стиле. Это **интерфейсный макет** с
эмулированными данными: реалистичные цены, но переводы, пополнения, обмены и балансы —
песочница в `localStorage`. Реальные интеграции подключаются по [PLAN.md](PLAN.md).

## Запуск

Нужен http-origin (ES-модули + `localStorage`). Открытие через `file://` не сработает.

```bash
C:\Users\User\AppData\Local\Programs\Python\Python313\python.exe serve.py 5174
```

Затем открыть `http://127.0.0.1:5174/`.

`serve.py` — не то же самое, что `python -m http.server`: он отдаёт всё с заголовком
`Cache-Control: no-store`. Штатный сервер позволяет браузеру кэшировать ES-модули, и после
правки файла продолжает исполняться старый код — отладка превращается в охоту за призраками.

## Данные

| Что | Откуда | Реально? |
|---|---|---|
| Цены 36 из 38 активов | Binance (REST + WebSocket), Coinbase, CoinGecko | **да** |
| Свечи, стакан, лента сделок | Binance | **да** |
| Сводная цена по 6 биржам | Binance, OKX, Bybit, Kraken, Bitstamp, Coinbase | **да** |
| Золото и серебро (XAU/XAG) | локальный симулятор | нет |
| Балансы, сделки, переводы | песочница в `localStorage` | **нет, эмуляция** |
| База пользователей в админке | синтетический генератор | **нет, эмуляция** |

Ключи API не используются, о пользователе никуда ничего не отправляется. При недоступности
сети всё откатывается на локальный симулятор — сайт не ломается офлайн.

## Админ-панель

`#/admin`, код доступа `meridian-admin`. Обзор со статистикой и графиками, управление
пользователями (поиск, фильтры, блокировка с обязательным основанием, массовые действия,
уровни KYC), рассылки, настройки площадки, журнал аудита.

> Код доступа зашит во фронтенд и виден любому — это **не аутентификация**, а элемент макета.
> Рассылки никуда не отправляются: меняется только статус записи.

## Что попробовать

1. Нажать **«Войти в демо-счёт»** (шапка) — создаётся демо-аккаунт с тестовыми балансами.
2. **Кошелёк** → «Пополнить» (эмуляция подтверждений сети) и «Вывести».
3. **Обмен (Convert)** — своп любого актива в любой по live-котировке.
4. **Торговля (Trade)** — график-свечи, стакан, лента, маркет/лимит ордера.
5. **Кабинет (Dashboard)** — портфель, аллокация, P&L, история.
6. **Купить крипту (Buy)** — эмуляция онрампа картой.
7. Сбросить песочницу: **Настройки → Сбросить демо-данные**.

## Бэкенд

Появился настоящий сервер — SQLite с двойной записью, матчинг-движок, подписанные
запросы. Только стандартная библиотека Python, без внешних зависимостей.

```bash
python -m server.app 8787
```

Отдаёт и API, и фронтенд на `http://127.0.0.1:8787/`. Подробности и коды ошибок —
в [server/README.md](server/README.md). Самопроверка денежного контура (26 проверок):

```bash
python -m server.selftest
```

Фронтенд работает и **без** бэкенда — на песочнице в `localStorage`. Сервер
подключается поверх, а не вместо.

## Безопасность

| Механизм | Где | Что даёт |
|---|---|---|
| CSP | `index.html` + оба сервера | `connect-src` — закрытый список бирж; инлайновые и внешние скрипты запрещены |
| Подпись HMAC-SHA256 | `js/api/sign.js` ↔ `server/security.py` | секрет не покидает браузер (`extractable: false`), повтор запроса невозможен |
| EIP-55 и контрольные суммы | `js/util/address.js` | опечатка в адресе ловится до отправки; keccak-256 написан вручную — в WebCrypto его нет |
| Защита домена | `js/util/origin-guard.js` | предупреждение, если сайт открыт на подменённом или омограф-домене |
| scrypt | `server/security.py` | перебор паролей на GPU несоизмеримо дорог |

Кружок актива (`coinIcon` в `js/ui.js`) деградирует по трём ступеням: настоящий логотип →
валютный глиф на фирменном фоне (TRY, AED, KZT, UAH, XAG) → тикер текстом (TON, NEAR, ARB,

`js/icons.js` генерируется скриптом `assets/icons/gen_icons.py`, вручную его не правят.
Условия лицензий и порядок обновления — в [assets/icons/LICENSES.md](assets/icons/LICENSES.md).

## Стек макета

Чистый статический фронт: HTML + ES-модули + CSS-переменные, графики на `<canvas>`,
свой роутер и состояние. Без сборки и внешних зависимостей — работает офлайн. Целевой
прод-стек (Next.js/TS, матчинг-движок, кастоди, KYC, платёжные рельсы) описан в
[PLAN.md](PLAN.md).

> ⚠️ Демо-вход — не аутентификация. Никаких реальных денег, ключей или блокчейна здесь нет.
